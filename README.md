# 三一重工财务指标可视化｜学习项目

一个用于**求职作品集**的 Python + Flask 小项目：把三一重工（600031）2019–2023 年的公开财务指标
整理成 CSV，落进 SQLite，再用 Flask 提供接口，前端用原生 Canvas 画趋势图和同业对比图。

> **定位说明（先看这一段）**
> 这是**学习 / 作品集项目**，不是企业生产系统。所有数据来自公开年报，不含任何企业内部数据。

---

## 一、3 分钟跑起来

```bash
# 1) 建虚拟环境
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

# 2) 装依赖（运行只需要 4 个包）
pip install -r requirements.txt

# 3) 把 CSV 落进 SQLite（生成 sany_financials.db）
python scripts/build_database.py

# 4) 启动
python app.py
```

浏览器打开 <http://127.0.0.1:5000>

能看到三一 5 年营收/净利趋势线 + 三家同业 ROE 柱状图，就算跑通了。

**跑不通时的自查顺序**

1. `pip install -r requirements.txt` 有没有报错 —— 常见是 pandas 版本太旧。
2. 有没有先跑 `scripts/build_database.py` —— 没建库时接口会报「数据库不存在」。
3. 端口 5000 被占用 —— 改 `app.py` 最后一行的 `port=5001`。

## 二、跑测试

```bash
pip install -r requirements-dev.txt
python -m pytest tests -v
```

应该看到 **13 passed**。

这些测试查的是**数据口径**，不是接口通不通，这是整个项目最值钱的地方：

- 营收同比必须与年报披露值一致（2020 +31.29%、2021 +6.82%、2022 −24.59%、**2023 −8.51%**）
- 2022 年比较基数使用年报追溯重述口径（营收 800.34495、归母净利 42.90386、
  经营现金流 41.00859、投资现金流 −18.40338、筹资现金流 48.26439）
- 经营活动 + 投资活动 + 筹资活动 + 汇率影响 = 现金净增加额，**五年逐年配平**
- 现金流字段不能是「填 0 假装有数据」
- 金额字段保留原始换算精度（亿元保留到 1e-5），不允许被展示用的四舍五入覆盖
- 2023 年总资产周转 0.4725 次 / 应收周转 2.9773 次 / 存货周转 2.6798 次 / 现金比率 53.71%
- 五年周转率、资产负债率、现金比率序列逐年核对
- 同业口径只保留三一重工、徐工机械、中联重科三家（已剔除不可比的振华重工）
- 同业 ROE 使用加权平均口径，EPS 使用基本每股收益
- 应收周转率排名必须与 PPT 结论一致（三一 > 徐工 > 中联）

**为什么值得写这 13 个测试？**
真实场景里，财务数据的坑几乎全在「口径」上：合并净利润还是归母净利润？合并报表还是母公司报表？
2022 年用的是原始披露数还是年报里追溯重述后的可比数？这些差异能让同一个结论差出好几个百分点。
把口径写成断言，是让分析结果**可被追溯验证**的最低成本手段。

## 三、接口

| 路径 | 作用 |
| --- | --- |
| `/` | 可视化页面（Canvas 趋势图 + 同业柱状图） |
| `/api/health` | 健康检查，返回数据库路径与是否存在 |
| `/api/financials` | 三一 2019–2023 全部指标 |
| `/api/peers` | 2023 年同业对标（ROE / 周转 / EPS / 每股经营现金流） |
| `/api/summary` | 最新一年核心指标 + 同比 |

## 五、数据口径说明

- `revenue` 使用**营业收入**口径；2022 年比较基数采用 2023 年报中**追溯重述**后的可比数（800.34495 亿），与年报官方披露的 −8.51% 一致。
- 金额单位统一为**亿元人民币**。CSV 保留原始换算精度（由千元/万元披露值换算而来），
  界面上按需要四舍五入展示。
- 2022 年关键可比数：营业收入 **800.34495**（年报追溯重述后）、归母净利润 **42.90386**、
  经营活动现金流 **41.00859**、投资活动现金流 **−18.40338**。
- 2019–2023 五年的经营/投资/筹资现金流、汇率影响、现金净增加额均已填充，且**每年配平**。
- 周转率、杠杆、现金比率字段统一采用公开年度指标口径。
- 总资产周转率 **0.4725**、应收周转 **2.9773** 为**平均余额口径**的计算结果；**年报披露口径为总资产周转 0.48 次、应收周转 2.92 次（含票据）**，两者定义不同，不是对错。
- `gross_margin` 使用整体毛利率口径（2022 年 24.02%、2023 年 27.71%）；
  **不要**与「按主营成本率反算的毛利率」混用 —— 那是两个不同口径。
- 同业对标范围仅三一重工、徐工机械、中联重科三家；ROE 用加权平均口径，EPS 用基本每股收益。
- 2023 年现金流桥接：**57.08220 − 26.93824 − 75.29791 − 0.38517 = −45.53912**，展示为 **−45.54**。
  分项四舍五入后相加可能与合计差 0.01，因为合计是按底层精度算出来的。

## 六、已知限制

1. 同业只做了 2023 年单年对标，没有做 5 年完整同业序列。
2. 前端图表用原生 Canvas 手写，没有引入 ECharts / Plotly；规模小够用，不适合做复杂交互。
3. 采购与销售、汇率桥接等口径做了简化，仅用于展示方法。
4. 数据依赖公开年报，未接入实时行情或财务数据库。
